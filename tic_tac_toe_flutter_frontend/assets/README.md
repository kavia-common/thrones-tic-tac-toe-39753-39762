# Assets

- assets/icons/got_x.png
- assets/icons/got_o.png

Replace these placeholders with final assets of the same filename and format for production branding.

assets:
  - assets/
  - assets/icons/
  - assets/icons/got_x.png
  - assets/icons/got_o.png
