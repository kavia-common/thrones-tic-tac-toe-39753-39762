# Run and Analyze

This is the Flutter app root.

Common commands:
- flutter pub get
- flutter analyze
- flutter test
- flutter run

From the workspace root:
- ../run_flutter_app.sh pub get
- ../flutter_ci.sh analyze
- ../flutter_ci.sh test
- make -C . analyze
- make -C . test

If you see “Could not determine project root directory for Flutter project”, ensure you are in this directory (tic_tac_toe_flutter_frontend) before running flutter commands.
