Development guide

- This is a Flutter app. Always run commands from this directory:
  thrones-tic-tac-toe-39753-39762/tic_tac_toe_flutter_frontend

- Setup and run:
  1) flutter pub get
  2) flutter analyze
  3) flutter run

- If you see "Target of URI doesn't exist: package:flutter/material.dart", it means `flutter pub get` was not run prior to analysis.
