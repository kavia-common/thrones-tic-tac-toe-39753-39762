# Flutter Project

The Flutter project for this workspace is located at:
- tic_tac_toe_flutter_frontend/

To analyze and run tests from the workspace root:
- ./run_mobile_analysis.sh
- ./run_flutter_checks.sh
- ./flutter_ci.sh analyze
- ./flutter_ci.sh test

Or run directly from the app directory:
- cd tic_tac_toe_flutter_frontend
- flutter pub get
- flutter analyze
- flutter test
- flutter run
