# Quick Commands

From workspace root:
- cd tic_tac_toe_flutter_frontend && flutter pub get && flutter analyze && flutter test
- ./analyze_and_test.sh
- ./flutter_ci.sh analyze
- ./flutter_ci.sh test
- make analyze
- make test

From app directory (tic_tac_toe_flutter_frontend):
- flutter pub get && flutter analyze && flutter test
- ./analyze_and_test.sh
- ./analyze.sh
- ./test.sh

If you see “Could not determine project root directory for Flutter project”, ensure the current directory is tic_tac_toe_flutter_frontend or use the helper scripts above.
