Flutter project root markers checklist

This directory is the Flutter app root. The following markers and files exist to help tools detect the project root:

Required by Flutter tool:
- pubspec.yaml
- lib/main.dart
- android/ (platform folder)
- analysis_options.yaml

Additional markers and helpers available in this folder:
- .metadata
- .gitignore
- analysis_options.local.yaml
- .packages (placeholder; will be regenerated by Flutter)
- PROJECT_ROOT.md
- README_ROOT.md
- check_flutter_root.sh
- check_pubspec.sh
- tool_sanity_check.dart
- tool_check_root.dart
- run_ci_sequence.sh

From repository root, helpers also exist:
- run_flutter_from_root.sh
- Makefile (targets run/analyze/test with cd into app root)
- PROJECT_ROOT.md
- MOBILE_ANALYZER_HINT.md

Usage:
- Always cd into this directory before running Flutter commands:
  cd thrones-tic-tac-toe-39753-39762/tic_tac_toe_flutter_frontend
- Then run:
  flutter pub get && flutter analyze && flutter test && flutter run

If your CI/mobile analyzer cannot detect the root automatically, configure it to run commands from this path, or invoke:
- bash ../../run_flutter_from_root.sh
